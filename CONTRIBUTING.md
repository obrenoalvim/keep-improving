# Contributing

The `skills/keep-improving/SKILL.md` is the source of truth. If you find a gap in the rules, a missing safe/sensitive distinction, or a rule that's wrong, open a PR against it.

## What to contribute

- New categories of "safe" changes that are genuinely reversible and low-risk
- Better research queries or additional research tools worth wiring in
- Sharper wording for the commit rule, if you find a rationalization it doesn't cover
- Platform-specific notes (test frameworks, UI conventions, etc.)

## How

1. Fork the repo
2. Edit `skills/keep-improving/SKILL.md`
3. Open a PR describing the gap this closes and why
